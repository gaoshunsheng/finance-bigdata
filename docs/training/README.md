# 用户培训材料

## 1. 规则编辑器
- 创建条件规则: 选择字段→选择运算符→输入值
- 逻辑组合: AND(全部满足)/OR(任一满足)/NOT(取反)
- 命中策略: FIRST_HIT(首条命中)/ALL(全部执行)/PRIORITY(按优先级)

## 2. 评分卡配置
- 添加特征→设置分箱(数值范围)→分配分数→设置cutoff阈值
- 实时预览得分计算过程

## 3. 决策流设计器
- 从左侧拖拽节点到画布(数据准备/规则集/评分卡/决策/动作)
- 连线建立执行顺序，可添加条件分支
- 保存时自动校验环检测

## 4. 沙箱测试
- 输入JSON格式测试数据→点击执行→查看完整TraceEntry路径
- 支持版本对比测试

## 5. 发布流程
草稿 → 测试 → 提交审批 → 审批通过 → 灰度(5%→50%) → 全量发布
- 每步支持回滚到任意历史版本
