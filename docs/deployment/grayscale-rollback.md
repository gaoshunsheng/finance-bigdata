# 灰度上线方案

## 1. 并行运行策略
- 新旧系统同时运行，通过网关按比例分流
- 新系统结果仅记录不生效，与旧系统结果对比

## 2. 流量切分方案
| 阶段 | 新系统流量 | 持续时间 | 通过条件 |
|------|-----------|---------|---------|
| 灰度1% | 1% | 2天 | 无错误 |
| 灰度5% | 5% | 3天 | 结果一致率>99.9% |
| 灰度50% | 50% | 3天 | P99<3s, QPS≥500 |
| 全量 | 100% | - | 全部指标达标 |

## 3. 数据一致性校验
- 每日对比新旧系统决策结果
- 差异率 > 0.1% 自动暂停灰度

## 4. 回滚预案
- API: `POST /api/v1/publish/{type}/{id}/grayscale/rollback`
- 一键回滚到上一版本，5秒内生效
- 版本对比: `GET /api/v1/publish/{type}/{id}/diff-latest`
