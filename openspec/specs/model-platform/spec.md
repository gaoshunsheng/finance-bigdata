# 模型平台规格

> 版本: 1.0 | 状态: Draft | 创建: 2026-06-03 | 关联: [平台总览](../platform-overview/spec.md)

---

## 1. 概述

模型平台管理信用评分、反欺诈等机器学习模型的全生命周期，与决策引擎通过模型推理服务解耦集成。

---

## 2. 模块 P1: 数据准备

### 2.1 样本管理

| 能力 | 规格 |
|------|------|
| 样本筛选 | 按时间窗口、产品类型、渠道、客户类型筛选 |
| 正负样本定义 | 可配置标签规则 (如: 逾期>90天为正样本) |
| 时间切分 | 训练集/验证集/测试集按时间窗口切分 (避免数据穿越) |
| 样本量 | 支持百万级样本 |
| 采样策略 | 欠采样/过采样/SMOTE |

### 2.2 特征工程

| 能力 | 规格 |
|------|------|
| 特征选择 | IV值筛选、相关性过滤、逐步回归 |
| 特征衍生 | 交叉组合、多项式、时序统计 (近N月max/min/avg/std) |
| WOE 编码 | 自动分箱 (等频/等距/决策树分箱) + WOE 转换 |
| 特征稳定性 | 自动计算 PSI, PSI > 0.25 的特征告警 |
| 特征复用 | 从变量引擎的 2000+ 变量中选取, 避免重复定义 |

## 3. 模块 P2: 模型训练

### 3.1 支持算法

| 算法 | 用途 | 输出格式 |
|------|------|----------|
| Logistic Regression | 标准评分卡 | PMML |
| XGBoost | 复杂非线性模型 | PMML / ONNX |
| LightGBM | 高性能梯度提升 | PMML / ONNX |
| 评分卡 (手动) | 业务专家规则 | JSON (自研格式) |

### 3.2 自动化训练

| 能力 | 规格 |
|------|------|
| 超参搜索 | Grid Search / Random Search / Bayesian Optimization |
| 交叉验证 | K-Fold (K=5/10) |
| 时间序列验证 | 滚动窗口验证 (金融场景必备) |
| 特征重要性 | 自动输出特征重要性排序 |
| 训练记录 | 记录每次训练的超参数、数据快照、评估指标 |

### 3.3 模型评估

| 指标 | 说明 | 阈值 |
|------|------|------|
| KS 值 | 区分度 | > 0.30 (上线要求) |
| AUC | ROC 曲线下面积 | > 0.70 |
| PSI | 稳定性 | < 0.10 (新模型 vs 旧模型) |
| 混淆矩阵 | 精确率/召回率/F1 | 按业务要求 |
| 提升度 | Lift @ Top 10% | > 3.0 |
| VIF | 多重共线性 (LR模型) | < 5.0 |

## 4. 模块 P3: 模型部署

### 4.1 模型导出

| 格式 | 适用模型 | 说明 |
|------|----------|------|
| PMML | LR, XGBoost, LightGBM | 标准 XML 格式, 兼容性好 |
| ONNX | XGBoost, LightGBM, 深度学习 | 高性能推理 |
| JSON | 手动评分卡 | 自研格式, 直接被决策引擎评分卡模块消费 |

### 4.2 推理服务

| 项目 | 规格 |
|------|------|
| **架构** | 独立微服务 (与决策引擎解耦) |
| **协议** | REST API + gRPC (高性能场景) |
| **并发** | 单实例 QPS ≥ 1000 |
| **延迟** | P99 < 50ms |
| **批量推理** | 支持批量预测 (T+1 评分场景) |
| **多版本** | 同一模型多版本共存 (支持灰度) |

### 4.3 灰度发布

模型上线走灰度流程:
1. 新模型部署为 v2, 旧模型保持为 v1
2. 通过决策引擎的 AB_SPLIT 节点分流
3. 对比 v1 和 v2 的 KS、通过率等指标
4. 指标达标后全量切换到 v2

## 5. 模块 P4: 模型监控

### 5.1 稳定性监控

| 监控项 | 频率 | 告警条件 |
|--------|------|----------|
| 模型 PSI | 日 | PSI > 0.10 预警, > 0.25 严重告警 |
| 特征分布漂移 | 周 | 单特征 PSI > 0.25 |
| 预测分布变化 | 日 | 预测分数分布偏离基线 |

### 5.2 效果监控

| 监控项 | 频率 | 说明 |
|--------|------|------|
| KS 值趋势 | 月 | 跟踪模型区分度衰减 |
| AUC 趋势 | 月 | 跟踪模型整体效果 |
| 排序性 | 月 | 按评分分组的实际不良率排序性 |
| 通过率 | 日 | 各评分段的审批通过率 |

### 5.3 告警与迭代

| 触发条件 | 动作 |
|----------|------|
| PSI > 0.25 连续 3 天 | 发送告警, 建议重训练 |
| KS 下降 > 20% | 自动创建重训练任务 |
| 通过率偏离 > 10% | 告警 + 人工评估 |
