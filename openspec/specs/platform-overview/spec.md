## 1. 平台定位

### 1.1 产品定义

企业征信大数据平台是集团内部信贷业务的基础设施，为信贷全生命周期（贷前审批、贷中监控、贷后管理）提供数据支撑、智能决策和模型服务能力。

### 1.2 核心特征

| 维度 | 定义 |
|------|------|
| **定位** | 集团内部基础设施（非 SaaS，不对服务外部客户） |
| **用户** | 风控策略师（业务人员）、风控分析师、数据工程师、模型工程师 |
| **数据规模** | 大型：日增 >5000 万条，总存储 >50TB |
| **实时性** | 贷前审批秒级（<3s）、贷中监控分钟级、报表 T+1 |
| **合规要求** | 高可解释性、完整审计追踪、满足银保监监管要求 |

### 1.3 核心设计原则

1. **自研决策引擎** — 完全自主可控，不依赖第三方规则引擎商业授权
2. **数据驱动** — 从数据接入到决策输出的全链路闭环
3. **业务人员可配置** — 风控策略师可自助配置规则、评分卡、决策流，无需写代码
4. **可解释性第一等公民** — 每笔决策可追溯、可解释、可审计
5. **编译执行** — 规则 JSON 编译为 AST 后缓存执行，引擎开销 < 50ms

## 3. 四大平台职责划分

### 3.1 大数据平台

**职责**: 数据的接入、存储、计算、治理和服务，为上层数据消费者提供统一的数据基座。

**核心模块**:

| 编号 | 模块 | 职责 |
|------|------|------|
| M1 | 数据采集 | 批量采集(CDC/DataX)、实时采集(Canal/Kafka)、外部数据采集、日志采集 |
| M2 | 数据存储 | 数据湖(HDFS)、数据仓库(Hive分层)、实时存储(Kafka)、KV存储(HBase)、搜索存储(ES) |
| M3 | 数据计算 | 离线计算(Spark)、实时计算(Flink)、即席查询(Presto/Trino) |
| M4 | 数据治理 | 元数据管理、数据质量、数据安全、生命周期 |
| M5 | 数据服务 | 数据API、BI报表、数据产品(企业画像/信用报告) |

### 3.2 决策引擎

**职责**: 基于大数据平台的数据，执行信贷决策的规则匹配、评分计算、流程编排和模型调用。

**核心模块**:

| 编号 | 模块 | 职责 |
|------|------|------|
| D1 | 接入层 | API网关、渠道管理、请求标准化 |
| D2 | 计算层 | 变量引擎、特征服务、衍生变量计算 |
| D3 | 决策层 | 规则引擎、评分卡引擎、决策流引擎、模型调用、AB实验、可解释性 |
| D4 | 管理平台 | 可视化编辑器(Vue前端)、策略版本管理、审批发布、沙箱回测、决策分析 |
| D5 | 数据层 | 规则存储(MySQL)、决策日志(ES)、特征缓存(Redis)、历史特征(HBase) |

### 3.3 模型平台

**职责**: 管理信用评分、反欺诈等机器学习模型的全生命周期。

**核心模块**:

| 编号 | 模块 | 职责 |
|------|------|------|
| P1 | 数据准备 | 样本管理、特征工程 |
| P2 | 模型训练 | 算法支持(LR/XGBoost/LightGBM)、自动化训练、模型评估 |
| P3 | 模型部署 | 模型导出(PMML/ONNX)、推理服务、灰度发布 |
| P4 | 模型监控 | 稳定性监控(PSI)、效果跟踪(KS/AUC)、告警与迭代 |

### 3.4 运维平台

**职责**: 保障全平台的稳定运行和高效运维。

**核心模块**:

| 编号 | 模块 | 职责 |
|------|------|------|
| O1 | 监控告警 | 基础设施监控、任务监控、业务监控 |
| O2 | 任务调度 | 调度引擎(DolphinScheduler)、依赖管理 |
| O3 | 成本优化 | 资源管控、冷热分层、存储治理 |

| **决策延迟** | 单笔 P99 | < 3 秒 |

| **可用性** | SLA | 99.9% |

| **变量容量** | 管理变量数 | ≥ 2000 个 |
