## 2. 分阶段交付

### Phase 0: 基础设施 + 技术预研 (Month 1-2)

**目标**: 搭建基础设施, 完成核心技术验证

**团队分配**:
- 大数据组 (2人): Hadoop/Kafka/Flink 集群搭建, 数据采集管道
- 引擎组 (3人): engine-core 骨架, Aviator 集成, 规则编译器 V1
- 前端组 (2人): Vue 骨架, DAG 画布选型验证, 交互原型

**交付物**:
| # | 交付物 | 验收标准 |
|---|--------|----------|
| 1 | 基础设施环境 | HDFS/Hive/Kafka/Flink/Redis/HBase/ES/MySQL 全部可运行 |
| 2 | 引擎原型 | 能编译执行一条简单条件规则 (JSON → AST → 结果) |
| 3 | 表达式引擎 | Aviator 集成完成, 自定义函数可注册调用 |
| 4 | 前端原型 | 规则编辑器交互原型 (可点击, 非 mockup) |

---

### Phase 1: 核心引擎 + 数据平台 (Month 3-5)

**目标**: 核心引擎可用, 大数据平台基础运行

**团队分配**:
- 引擎组 (4人): 评分卡/决策表/DAG/变量引擎/热加载/追踪
- 大数据组 (2人): Hive 数仓分层, Flink 实时特征, 特征存储
- 前端组 (2人): 规则编辑器, 评分卡编辑器, DAG 设计器, 变量管理

**交付物**:
| # | 交付物 | 验收标准 |
|---|--------|----------|
| 1 | 规则引擎 | 支持条件规则/评分卡/决策表/规则集 4 种类型 |
| 2 | 决策流引擎 | DAG 编排 + 拓扑排序 + 并行执行 + 条件分支 |
| 3 | 变量引擎 | 注册表 + 懒加载 + 预取 + 并行获取 |
| 4 | 热加载 | 规则变更后 <5s 生效, 不中断在线请求 |
| 5 | Hive 数仓 | ODS/DWD/DWS/ADS 四层建模完成 |
| 6 | Flink 实时特征 | ≥5 个实时特征任务上线, 延迟 <5s |
| 7 | 管理后台 MVP | 规则/评分卡/决策流可视化编辑 + 保存 |

**里程碑**: 端到端演示 — 一笔模拟申请走完完整决策流 (含规则+评分卡+模型调用mock)

---

### Phase 2: 决策引擎完善 + 外部数据接入 (Month 6-8)

**目标**: 完整的决策引擎上线, 外部数据全量接入

**团队分配**:
- 引擎组 (3人): AB 实验, 模型调用, 外部数据获取, 沙箱回测, 性能调优
- 后台组 (3人): 发布流程, 权限管理, 分析看板, 实验管理
- 大数据组 (2人): 外部数据 ETL, 数据质量, 元数据管理
- 前端组 (2人): 分析看板, 实验页面, 发布中心, 决策报告

**交付物**:
| # | 交付物 | 验收标准 |
|---|--------|----------|
| 1 | AB 实验引擎 | 分流 + 指标收集 + 显著性分析 + 自动回滚 |
| 2 | 模型调用引擎 | PMML/ONNX 推理服务集成, 单次 <50ms |
| 3 | 外部数据获取 | ≥5 个外部 API 适配器 (征信/工商/司法/运营商) |
| 4 | 沙箱回测 | 历史数据回放 + 对比报告 |
| 5 | 发布流程 | 草稿→测试→审批→灰度→全量 完整流程 |
| 6 | 性能达标 | 单机 QPS ≥500, P99 <3s (压测报告) |
| 7 | 管理后台完整 | 所有管理功能上线 |

**里程碑**: 决策引擎 UAT — 使用真实外部数据完成端到端测试

---

### Phase 3: 模型平台 + 系统联调 + 上线 (Month 9-12)

**目标**: 三平台完整交付, 生产上线

**团队分配**:
- 模型组 (3人): 样本管理, 特征工程, 模型训练/评估/部署/监控
- 联调组 (全团队): 端到端集成测试, 性能压测, 安全加固

**交付物**:
| # | 交付物 | 验收标准 |
|---|--------|----------|
| 1 | 模型平台 | 样本→训练→评估→部署→监控 全流程 |
| 2 | 端到端联调 | 大数据→决策引擎→模型平台 全链路通过 |
| 3 | 性能全链路 | 生产环境 QPS/延迟/可用性达标 |
| 4 | 安全审计 | 数据脱敏/加密/权限/审计 全部通过 |
| 5 | 监控运维 | 全链路监控告警体系上线 |
| 6 | 文档 | 架构文档 + API 文档 + 运维手册 + 培训材料 |
| 7 | 生产上线 | 灰度 → 全量上线 |

## 4. 风险登记

| # | 风险 | 影响 | 概率 | 应对 |
|---|------|------|------|------|
| 1 | 可视化编辑器开发量超预期 | Phase 1-2 延期 | 高 | 用 AntV X6 + Handsontable 减少自研量; 先做核心编辑器, 决策表可后置 |
| 2 | 引擎性能不达标 | Phase 2 延期 | 中 | Phase 1 就建性能基准; 最坏水平扩展 |
| 3 | 外部 API 不稳定 | Phase 2 延期 | 中 | 缓存+降级+超时; 预留 Mock 模式 |
| 4 | 数千变量管理复杂度 | 长期维护风险 | 高 | 分域管理; 版本化; 自动依赖分析 |
| 5 | 大团队协作效率 | 各 Phase | 中 | engine-core 纯 Java 解耦; 清晰接口契约; 双周集成演示 |
