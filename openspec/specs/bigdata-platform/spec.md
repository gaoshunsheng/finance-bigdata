## 1. 模块 M1: 数据采集

### 1.1 批量采集

| 项目 | 规格 |
|------|------|
| **工具** | DataX (首选) / Sqoop (备选) |
| **源端** | MySQL、Oracle、PostgreSQL |
| **目标端** | HDFS (ODS 层) |
| **调度** | DolphinScheduler 定时触发 |
| **频率** | T+1 日增量同步（凌晨低峰期） |
| **数据量** | 单表最大 5 亿行 |
| **断点续传** | 支持 |
| **数据校验** | 源端与目标端行数对比 + 抽样字段校验 |

### 1.2 实时采集 (CDC)

| 项目 | 规格 |
|------|------|
| **工具** | Canal (MySQL) / Debezium (Oracle) |
| **目标** | Kafka |
| **延迟** | < 5 秒 |
| **消息格式** | JSON (含 op_type / before / after / ts) |
| **消费者** | Flink 流处理 |
| **断点恢复** | 基于 Kafka offset |

### 1.3 外部数据采集

| 项目 | 规格 |
|------|------|
| **接入方式** | HTTP API 调用 → 清洗转换 → HDFS + HBase |
| **调度** | 决策引擎实时调用 + 定时批量同步 |
| **缓存** | Redis 缓存热点查询结果 (TTL 可配置) |
| **限流** | 按 API 供应商限流要求配置 |
| **降级** | API 不可用时返回缓存或默认值 |

### 1.4 日志采集

| 项目 | 规格 |
|------|------|
| **工具** | Fluentd / Filebeat |
| **目标** | Kafka → HDFS (持久化) + ES (实时检索) |
| **日志类型** | 应用日志、访问日志、业务埋点日志 |
| **格式** | JSON 结构化日志 |

## 2. 模块 M2: 数据存储

### 2.1 数据分层架构

```
┌──────────────────────────────────────────────────────────┐
│                    数据分层模型                            │
│                                                          │
│  ADS (应用数据层)                                         │
│  ├── 信用评分宽表                                         │
│  ├── 风控指标汇总表                                       │
│  └── 决策分析主题表                                       │
│          ▲                                               │
│  DWS (汇总数据层)                                         │
│  ├── 客户维度汇总 (近N月指标)                              │
│  ├── 产品维度汇总                                         │
│  └── 渠道维度汇总                                         │
│          ▲                                               │
│  DWD (明细数据层)                                         │
│  ├── 标准化业务明细 (清洗、脱敏、统一编码)                  │
│  └── 关联外部数据明细                                     │
│          ▲                                               │
│  ODS (原始数据层)                                         │
│  ├── 业务系统原始数据 (MySQL/Oracle 同步)                  │
│  ├── 外部数据源原始报文                                   │
│  └── 日志原始数据                                        │
│          ▲                                               │
│  数据源: MySQL / Oracle / 外部API / 日志文件               │
└──────────────────────────────────────────────────────────┘
```

### 2.2 存储技术矩阵

| 存储需求 | 技术选型 | 数据类型 | 保留策略 |
|----------|----------|----------|----------|
| 原始数据全量 | HDFS | Parquet/ORC 文件 | ODS: 2年, DWD+: 5年 |
| 数仓分层 | Hive | 分区表 (按日分区) | 按层分级管理 |
| 实时数据流 | Kafka | JSON 消息 | 7天 (按 Topic 配置) |
| 高维特征/历史查询 | HBase | KV (RowKey = 客户ID + 时间戳) | 3年 |
| 实时特征缓存 | Redis Cluster | String/Hash | TTL 1-24h (按特征配置) |
| 决策日志/审计 | Elasticsearch | JSON 文档 | 5年 (ILM 冷热分层) |

## 3. 模块 M3: 数据计算

### 3.1 离线计算 (Spark)

| 场景 | 频率 | 资源 |
|------|------|------|
| ODS → DWD 清洗转换 | T+1 日 | Spark SQL, 10-50 executor |
| DWD → DWS 聚合计算 | T+1 日 | Spark SQL, 5-20 executor |
| DWS → ADS 应用计算 | T+1 日 | Spark SQL, 5-10 executor |
| 模型特征离线计算 | T+1 日 | PySpark, 10-30 executor |
| 历史数据回刷 | 按需 | Spark, 弹性分配 |

### 3.2 实时计算 (Flink)

| 场景 | 延迟 | 说明 |
|------|------|------|
| 实时特征计算 | < 5s | 近N月逾期次数、查询次数、交易频次等 |
| 实时监控预警 | < 30s | 异常行为检测、额度使用率预警 |
| 实时指标看板 | < 60s | 通过率、转化率、放款量 |
| 数据质量检测 | < 30s | 数据新鲜度、完整性实时监控 |

**关键 Flink 任务清单**:

| 任务ID | 任务名 | 源 | 目标 | 窗口 |
|--------|--------|-----|------|------|
| FLINK_001 | 近3月征信查询次数 | Kafka (CDC) | Redis | 滑动窗口 90天 |
| FLINK_002 | 近6月逾期次数统计 | Kafka (CDC) | Redis | 滑动窗口 180天 |
| FLINK_003 | 近1月申请频次 | Kafka (埋点) | Redis | 滑动窗口 30天 |
| FLINK_004 | 实时交易金额汇总 | Kafka (交易) | HBase | 滚动窗口 1小时 |
| FLINK_005 | 数据质量检测 | Kafka (CDC) | ES + 告警 | 事件驱动 |

### 3.3 即席查询

| 项目 | 规格 |
|------|------|
| **引擎** | Trino (Presto) |
| **数据源** | Hive + HBase + MySQL |
| **用户** | 数据分析师 |
| **并发** | ≤ 20 个并发查询 |
| **超时** | 单查询 30 分钟 |
| **行级权限** | 基于用户角色的数据过滤 |

## 4. 模块 M4: 数据治理

### 4.1 元数据管理

| 能力 | 规格 |
|------|------|
| **数据资产目录** | 自动采集 Hive/MySQL/HBase 表结构, 统一编目 |
| **数据血缘** | 自动解析 SQL/DAG 依赖, 可视化血缘图 |
| **变更影响分析** | 表/字段变更时自动分析下游影响 |
| **标签体系** | 支持为表/字段打标签 (业务域/安全级别/数据Owner) |

### 4.2 数据质量

| 维度 | 监控规则 | 告警方式 |
|------|----------|----------|
| **完整性** | 字段空值率 > 阈值 | 企微/邮件 |
| **准确性** | 枚举值校验、范围校验、正则校验 | 企微/邮件 |
| **一致性** | 跨表关联一致性校验 | 企微/邮件 |
| **及时性** | 数据产出时间 > SLA | 电话/企微 |
| **唯一性** | 主键重复检测 | 企微/邮件 |

### 4.3 数据安全

| 能力 | 规格 |
|------|------|
| **分级分类** | 公开 / 内部 / 机密 / 绝密 四级 |
| **脱敏规则** | 身份证/手机号/银行卡号 自动脱敏 |
| **加密存储** | 机密级以上字段 AES-256 加密 |
| **权限控制** | RBAC, 行级/列级权限 |
| **审计日志** | 所有数据访问操作记录, 保留 5 年 |
| **传输加密** | TLS 1.3 |

### 4.4 生命周期管理

| 数据层级 | 热数据 | 温数据 | 冷数据 | 归档/删除 |
|----------|--------|--------|--------|-----------|
| ODS | 30天 | 6个月 | 2年 | 归档至冷存储 |
| DWD | 90天 | 1年 | 3年 | 归档至冷存储 |
| DWS | 6个月 | 2年 | 3年 | 归档至冷存储 |
| ADS | 1年 | 3年 | 5年 | 归档 |
| ES日志 | 7天(SSD) | 90天(HDD) | 1年(冷) | ILM 自动管理 |
| Redis | TTL 自动过期 | — | — | — |

## 5. 模块 M5: 数据服务

### 5.1 数据 API

| API 类型 | 用途 | 性能要求 |
|----------|------|----------|
| 实时特征查询 | 供决策引擎查询客户特征 | P99 < 20ms |
| 企业画像查询 | 供风控人员查看企业全貌 | P99 < 500ms |
| 数据订阅 | 供下游系统订阅变更事件 | 延迟 < 5s |

### 5.2 BI 报表

| 报表类型 | 内容 | 刷新频率 |
|----------|------|----------|
| 经营分析看板 | 放款量/通过率/不良率 | T+1 |
| 风控监控看板 | 规则命中率/模型KS值 | 实时 |
| 渠道分析看板 | 各渠道申请量/转化率 | T+1 |
| 数据质量看板 | 完整性/准确性指标 | 实时 |

### 5.3 数据产品

| 产品 | 功能 | 用户 |
|------|------|------|
| 企业 360 画像 | 企业全维度信息展示 | 风控专员 |
| 信用评分报告 | 单笔决策的完整分析报告 | 风控专员/审批员 |
| 风险预警中心 | 贷中风险预警信号 | 风控专员 |
